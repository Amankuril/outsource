# TechLinked

Hospitality community app — Home feed and Opportunities pages, built from the Figma design with React, Vite, TypeScript and Tailwind CSS.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Pages

- `/` — Home: profile, quick links, post composer, feed, opportunities, progress, upcoming activity
- `/opportunities` — listings with type tabs, search, filters, apply/save, post-an-opportunity form

Desktop layout from 1024px up; mobile layout (bottom nav, filter sheet) below that.
